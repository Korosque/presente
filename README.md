# Para Carolina

Experiência de aniversário estática, feita com HTML, CSS e JavaScript vanilla.

## Personalização rápida

Abra `js/script.js` e edite o objeto `CONFIG` no começo do arquivo:

- `name`: nome exibido na experiência.
- `timeline`: datas, títulos e textos da história.
- `letter`: texto completo da carta.
- `moments`: pequenos destaques do relacionamento.
- `finalMessage`: mensagem final.
- `music`: caminho opcional, por exemplo `assets/music/nossa-musica.mp3`.

As fotos reais estão em `assets/photos/`. Para trocar uma foto, mantenha o nome do arquivo ou atualize a lista `photos` no JavaScript. A galeria já aceita proporções diferentes e abre as imagens em tela ampliada, com navegação por toque.


## Hospedagem

Abra `index.html` localmente ou publique a pasta inteira em GitHub Pages, Netlify ou Vercel. Não há dependências nem backend.
